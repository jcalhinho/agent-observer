Guidelines:

- Use a demo workspace: no real client names, private paths, prompts or tokens on screen.
- Take them from the demo data, never your own sessions. 1440 × 900 is enough (the hero is 1600 × 960); optimise with `oxipng` or `pngquant`.
- Regenerate every image when the design changes: they are part of the documentation.
- GIFs, if you add any, stay under 5 MB.
